## 🧪 FEATURED EXPERIMENT // FOOTBALL SCIENTIST

> **An AI-powered football intelligence platform built to turn match data, context and live web information into structured analysis.**

[![Repository](https://img.shields.io/badge/OPEN_REPOSITORY-Football_Scientist-00C896?style=for-the-badge&logo=github&logoColor=white)](https://github.com/STARBOYINNIT/THEFOOTBALLSCIENTIST)

**What it does**

- ⚽ Generates structured fixture and tactical analysis
- 🌐 Uses Gemini with Google Search grounding for current information
- 🧠 Runs a multi-layer reasoning framework covering context, tactics, statistics, players, scenarios and risk
- 📊 Produces predictions, confidence levels, score scenarios and safer alternatives
- ✅ Lets predictions be verified as correct or incorrect
- 📈 Tracks historical prediction accuracy and recent form
- 📰 Surfaces grounded football news and source links
- 💾 Persists prediction history locally

**Engineering**

`React 19` · `TypeScript` · `Vite` · `Google Gemini` · `Google GenAI SDK` · `Google Search Grounding` · `LocalStorage`
